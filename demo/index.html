Warum eine statische Demo?

GitHub Pages führt kein PHP aus. Die Preview bildet deshalb ausgewählte Abläufe mit synthetischen Browserdaten nach, während das eigentliche Laravel-Projekt unverändert als prüfbarer Quellcode erhalten bleibt.
